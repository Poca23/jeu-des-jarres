# Jeu des Jarres

Jeu PHP en ligne de commande — 3 niveaux, des jarres, des clés et des serpents.

## Lancer le jeu

```bash
php game.php
```

## Niveaux

| Niveau | Objectif                                     |
| ------ | -------------------------------------------- |
| 1      | Trouver une clé parmi 5 jarres               |
| 2      | Trouver 3 clés consécutives                  |
| 3      | Choisir une difficulté, puis trouver une clé |

## Structure

```
jeu-des-jarres/
├── game.php    ← point d'entrée
├── level1.php
├── level2.php
└── level3.php
```

## Prérequis

- PHP 7.4+
- Terminal / CLI

